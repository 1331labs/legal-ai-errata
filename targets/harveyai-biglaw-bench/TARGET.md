BigLaw Bench is a sample-only repository: `blb-core/core-samples.csv` (six sample tasks with point rubrics and source PDFs), `blb-workflows/spa` (a schema, a samples file and ten share purchase agreements) and `blb-retrieval` (a samples file with merger agreements, SPAs and discovery emails). The README states that scores combine "positive points for meeting task requirements and negative points for errors or missteps (e.g. hallucinations)" and that the full dataset is available by contacting the publisher.

## How corrections are accepted

Issue. The repository has no licence file and no contribution guide, so corrections are given as old and new text and no modified file is distributed.
