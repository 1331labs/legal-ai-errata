Self-hosted legal AI application with a built-in skill and playbook library (NDA, MSA, DPA and privacy review, contract question answering, case-law research), a citation verification engine and an anonymization layer for cloud inference.

## How corrections are accepted

Issue first, then a pull request from a fork. skills/CONTRIBUTING.md asks for a tracking issue, an attestation in the pull request and review by a practicing attorney and an engineer; the root CONTRIBUTING.md requires DCO sign-off on every commit.
