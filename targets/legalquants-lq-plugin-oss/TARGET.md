Twenty-four lawyer-facing agent skills and seven companion skills (instruction files, reference files, scripts and schemas), built into three plugins: litigation, transactional and companion. Authored source is under `skills/`; the `plugins/` directories are generated by `pnpm pluginctl pack` and are not edited by hand.

## How corrections are accepted

Pull request. CONTRIBUTING.md sends small reproducible fixes straight to a pull request. Changes are made under skills/ and the plugins/ tree is regenerated with the pack command.
